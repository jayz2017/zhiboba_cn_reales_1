# 04 数据库设计（门禁：DDL 评审与可回滚）

## 输入
- 领域/数据模型

## 产物（必须交付）
- DDL：放置在 app/db/ddl/，按序号版本化
- DML（INSERT）：放置在 app/db/dml/inserts/，按序号版本化
- 索引策略：按查询场景设计（时间范围、game_id、全文检索）
- 迁移策略：新版本只追加，不覆盖历史（需要回滚脚本时必须提供）

## 检查清单
- 每张表有主键、关键索引、字符集与排序规则统一
- 关键唯一性约束存在（例如 nba_game 的自然唯一键）
- 原始数据与证据链保留（raw_json、evidence_live_event_id）
