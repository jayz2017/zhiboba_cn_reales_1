# 季后赛对阵赛程

## 适用场景（何时调用）
- 用户要求获取/同步“直播吧（zhibo8）NBA 季后赛对阵赛程”并写入 MySQL。
- 提取季后赛（包含总决赛）的对阵列表，并跳过未确定时间、未确定球队（含“待定”字样）的比赛。

## 请求信息

### URL
- 基础 URL：`https://stats.qiumibao.com/shuju/public/index.php`

### Method
- `GET`

### Params（必须）
- `_url`：`/data/index`
- `league`：`NBA`
- `tab`：`对阵`
- `type`：`对阵`
- `year`：动态值（默认 `YYYY`，若当前月份 < 9，则 `year = YYYY - 1`）
- `_t`：当前时间戳（毫秒）
- `appname`：`zhibo8`

### Headers（建议）
- `accept: application/json, text/plain, */*`
- `origin: https://m.zhibo8.com`
- `user-agent: (保持浏览器 UA)`

## 返回结构解析

### 提取规则
1. 季后赛对阵树分为 `top`、`bottom` 和 `finals` 三大块。
2. 遍历这些结构寻找嵌套在内部的 `schedule.list` 数组。
3. 对每个比赛节点，**如果 `date_str`、`time`、`date` 中包含 "待定"，或 `left_team` / `right_team` 包含 "待定"，直接抛弃该条记录。**
4. 提取 `saishi_id`（对应 `id`）、`home_id`（对应 `right_team_id`）、`guest_id`（对应 `left_team_id`）、`start_time`（对应 `time` 补齐秒数）、`event_name`（对应 `rounds`）。
5. 提取 `game_date`：利用 `url` 中包含的年份结合 `date` 中的 `月/日` 拼装成 `YYYY-MM-DD` 格式。

## MySQL 落库

- 与常规赛程复用同一张表 `nba_zhiboba_yj_gamelist`
- `saishi_id` 为唯一键，采用 `ON DUPLICATE KEY UPDATE` 的幂等方式落库。

## 代码位置
- 解析与数据获取模块：`app/modules/nba_schedule/zhiboba_playoffs.py`
- API 接口：`POST /api/v1/schedule/zhiboba/playoffs/sync`
