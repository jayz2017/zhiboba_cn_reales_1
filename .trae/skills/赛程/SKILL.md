# 赛程（直播吧 NBA）

## 适用场景（何时调用）
- 用户要求同步 NBA 常规赛 / 总赛程
- 用户要求同步 NBA 季后赛 / 对阵赛程
- 用户要求查看赛程相关表结构、字段映射或落库逻辑

## 能力范围

### 1. 常规赛 / 总赛程同步
- 对应能力：
  - 拉取直播吧指定年份的全部赛程
  - 增量落库到 `nba_zhiboba_yj_gamelist`
- 推荐触发指令：
  - `同步 2025 年 NBA 总赛程`
  - `拉取直播吧常规赛赛程并落库`
  - `执行总赛程同步`

### 2. 季后赛对阵同步
- 对应能力：
  - 拉取直播吧季后赛（含总决赛）对阵数据
  - 过滤待定场次并落库
- 推荐触发指令：
  - `同步 2025 年季后赛对阵`
  - `拉取季后赛赛程`
  - `执行季后赛对阵同步`

### 3. 赛程数据库设计说明
- 对应能力：
  - 查看 `game_list`
  - 查看 `nba_zhiboba_yj_gamelist`
  - 查看球队表、球员表与比赛关系
- 推荐触发指令：
  - `查看赛程表结构`
  - `解释赛程库表设计`
  - `赛程相关数据库字段说明`

## 主要表
- `game_list`
  - 保存当天运行赛程
- `nba_zhiboba_yj_gamelist`
  - 保存整赛季赛程数据
- `nba_teams_name_data`
  - 保存球队主数据
- `nba_players_name_data`
  - 保存球队球员数据

## 相关 API
- `POST /api/v1/schedule/zhiboba/sync`
- `POST /api/v1/schedule/zhiboba/playoffs/sync`
