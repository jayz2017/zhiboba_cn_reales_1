# 全局总管理（Skill 总控入口）

## 适用场景（何时调用）
- 用户想让系统“统筹全局”处理当前项目能力
- 用户不知道该调用哪个 skill，希望自动分流
- 用户一句话里同时包含“赛程 / 球员 / 直播文本抓取 / 分词 / API 调用”等多个任务

## 当前 Skill 全景

### 1. 赛程
- 作用：
  - 同步常规赛/总赛程
  - 处理赛程相关数据库设计说明
- 推荐触发指令：
  - `同步 2025 年 NBA 总赛程`
  - `拉取直播吧赛程并落库`
  - `查看赛程表结构`

### 2. 球队球员
- 作用：
  - 同步球队球员名单、球衣号、薪资、位置
  - 落库到 `nba_players_name_data`
- 推荐触发指令：
  - `同步老鹰队球员名单`
  - `抓取 team_id=6916 的球队球员信息`
  - `拉取直播吧球队球员并落库`

### 3. 比赛文本抓取
- 作用：
  - 按 `saishi_id` 抓取比赛直播文本事件
  - 处理 `start_cursor=1650`、分页、`404` 自动递增、`pid_text=比赛结束` 终止
  - 事件落库
- 推荐触发指令：
  - `抓取 saishi_id=1976690 的比赛直播文本`
  - `按 1650 起点同步比赛文本`
  - `抓取直播文本并处理 404 分页规则`

### 4. 直播文本分词
- 作用：
  - 用 PaddleNLP `TaskFlow` 对 `live_text` 分词
  - 自动灌入本场球员词典
  - 过滤语气助词并写入 token 表
- 推荐触发指令：
  - `对 saishi_id=1976690 的 live_text 分词`
  - `用球员词典优先切分比赛直播文本`
  - `分析直播文本分词结果`

### 5. 比赛直播文本
- 作用：
  - 总入口，只做“抓取”和“分词”的分流
- 推荐触发指令：
  - `我要处理比赛直播文本`
  - `帮我做比赛文本能力分流`

### 6. 球员别名
- 作用：
  - 根据 `nba_zhiboba_yj_gamelist` 中的 `game_date + saishi_id`
  - 抓取比赛球员中文别名
  - 写入 `player_alias_name_info`
  - 按 `player_id + alias_name` 去重
- 推荐触发指令：
  - `同步球员别名`
  - `抓取比赛球员中文别名`
  - `根据赛程表批量同步球员别名`

### 7. 指定日期赛程明细
- 作用：
  - 按指定日期从 `nba_zhiboba_yj_gamelist` 读取赛程
  - 按 `home_id / guest_id -> zhiboba_team_id` 关联 `nba_teams_name_data`
  - 补全 `home_team / visit_team` 并写入 `game_list`
- 推荐触发指令：
  - `按日期获取赛程明细`
  - `同步 2026-05-16 的赛程到 game_list`
  - `根据指定日期补全主客队名称并写入 game_list`

### 8. API 总调度
- 作用：
  - 统一分流当前项目所有 FastAPI 接口
- 推荐触发指令：
  - `调用赛程同步 API`
  - `调用球员同步 API`
  - `调用按球队ID同步球员 API`
  - `调用按直播吧球队ID绑定球员 team_id API`
  - `调用比赛直播文本同步 API`

## 分流规则
- 如果用户提到：
  - `赛程 / 年份 / 常规赛 / 总赛程 / 季后赛`
  - 分流到 `赛程`
- 如果用户提到：
  - `球队 / 球员 / team_id / 薪资 / 位置`
  - 分流到 `球队球员`
- 如果用户提到：
  - `saishi_id / 直播文本抓取 / 404 / start_cursor / 比赛结束`
  - 分流到 `比赛文本抓取`
- 如果用户提到：
  - `分词 / token / 球员词典 / TaskFlow / live_text 分析`
  - 分流到 `直播文本分词`
- 如果用户提到：
  - `球员别名 / 中文别名 / alias_name / player_alias_name_info`
  - 分流到 `球员别名`
- 如果用户提到：
  - `指定日期 / 当天赛程 / game_list / home_team / visit_team / season_type`
  - 分流到 `指定日期赛程明细`
- 如果用户明确要：
  - `接口 / API / Swagger / 调用接口`
  - 分流到 `API 总调度`

## 推荐总控指令
- `帮我同步 2025 年总赛程`
- `帮我抓取 saishi_id=1976690 的比赛文本并分词`
- `帮我同步 team_id=6916 的球员信息`
- `帮我同步球员别名`
- `帮我按日期同步赛程明细到 game_list`
- `告诉我这件事应该调用哪个 skill`
- `帮我调用对应的 API，不走手工拼地址`

## 执行顺序建议
- 若用户要“抓取 + 分词”：
  1. 先调用 `比赛文本抓取`
  2. 再调用 `直播文本分词`
- 若用户要“赛程 + 球员 + 分词联动”：
  1. 先 `赛程`
  2. 再 `球队球员`
  3. 再 `比赛文本抓取`
  4. 最后 `直播文本分词`

## 注意事项
- 本 skill 只负责全局编排与分流，不直接承载具体抓取或分词细节。
- 如用户已经明确目标，应优先调用对应的专用 skill，而不是停留在总管理层。
