# 比赛直播文本（总入口）

## 适用场景（何时调用）
- 用户只说“比赛直播文本”，但没有明确是要“抓取事件”还是“分词处理”
- 用户要求同时完成“抓取 + 分词”，需要先拆解步骤再执行
- 需要为后续流程选择正确 skill 入口时

## 分流规则
- 如果需求重点是：
  - URL 抓取
  - 分页游标
  - `404` 自动重试
  - `pid_text=比赛结束` 终止
  - 原始事件字段解析/落库
  则调用 `比赛文本抓取`

- 如果需求重点是：
  - 对 `live_text` 做中文分词
  - 基于比赛双方球员名单构建词典
  - 过滤语气助词/虚词
  - token 落库
  则调用 `直播文本分词`

## 推荐调用顺序
1. 先调用 `比赛文本抓取`，把直播文本事件抓取并落入事件表。
2. 再调用 `直播文本分词`，按 `saishi_id` 或事件集对 `live_text` 批量分词。
3. 如果用户明确要求“一步完成”，仍按上述两个子步骤顺序执行。

## 注意事项
- 不再把“抓取”和“分词”写在一个 skill 内混用，避免职责过重。
- 默认优先使用拆分后的两个 skill，不建议继续扩展本总入口的业务细节。
